# Colección de Pequeños Proyectos de Práctica

## Introducción 
---
El presente repositorio es una colección de proyectos de práctica, para poder familiarizarme con las diversas tecnologías del mundo de los datos, los proyectos, guardan cierta relación, porque, son sobre le mismo tema, sin embargo, no están integrados entre sí, todos los proyectos son de cursos de Luke Barousse, con modificaciones y adaptaciones propias. 

## Análisis Excel 
---
![Análisis Excel](Análisis-Excel/Imagenes/1-Salarios-vs-habilidades.png)
Pequeño, proyecto en Excel, que busca realizar un análisis de los salarios dependiendo del número de habilidades y los países donde se realizan estas ofertas. 
Se utilizan las siguientes herramientas: 
- Power Pivot
- Power Query
- Dax (Data Analysis Expresion)
- Tabla Dinámicas
- Gráficos Dinámicos

## Análisis Python 
---
![Análisis Python](Análisis-Python/Imagenes/5-Habilidades-mas-optimas-de-aprender.png)
Proyecto de análisis de datos, que busca responder preguntas puntuales, encontrar correlaciones y conclusiones sobre la importancia de manejar determinas habilidades dependiendo del puesto al que se aspira. 
Se utilizan las siguientes herramientas:
- Python
  - Librería Pandas
  - Librería Matplotlib
  - Librería Seaborn
- Visual Estudio Code
- Jupyter Notebook

## Reporte Excel
---

Pequeño reporte de Excel que busca mostrar la cantidad de ofertas de trabajo, la mediana del salario anual y la plataforma que brinda mayor cantidad de ofertas. 
**Consideración**: Esta no es la mejor manera de crear reportes o visualizar información, sin embargo, el objetivo principal del proyecto, es mostrar mi capacidad de manejar formulas y funciones en Excel.
Se utilizan las siguientes herramientas:
- Formulas y funciones
- Gráficos
- Validación de Datos
